# PATCH: KOI CLEAN ASSETS LAYOUT & TEXT OVERFLOW FIX V1.4

## Главная задача

Исправить сломанное отображение обучающих диалогов KOI поверх существующего зацикленного HUB VIDEO.

Патч не меняет фон HUB, видео, музыку, интерактивные здания и игровую логику. Он заменяет только визуальные ассеты KOI и полностью стабилизирует расположение персонажа, текста и кнопок.

## Что исправлено

### 1. Удалён клетчатый/белый технический фон

Новые присланные изображения KOI обработаны и сохранены как настоящие PNG с прозрачным фоном.

В игре больше не должны появляться:

- серо-белые квадраты;
- белые прямоугольники вокруг персонажа;
- технический фон исходного изображения.

### 2. Добавлены пять чистых pose-ассетов

Используются отдельные позы для:

- приветствия;
- Примерочной;
- Раменной;
- Разломов;
- Дома охотника.

Все позы приведены к единой высоте и отображаются в одном стабильном контейнере.

### 3. Пересобран layout диалога

Новая структура:

```text
HUB VIDEO BG
→ подсветка здания
→ KOI portrait layer
→ reference dialogue panel
→ fixed text area
→ fixed controls area
```

Персонаж больше не двигает панель и не влияет на ширину текста.

### 4. Исправлен выезд текста

Для текста задана отдельная безопасная область внутри панели:

- фиксированный левый отступ от KOI;
- ограниченная ширина;
- контролируемая высота;
- перенос только между словами;
- сохранение заданных переносов строк;
- адаптивный размер шрифта.

Заголовок, название локации, основной текст и счётчик шагов теперь имеют отдельные позиции.

### 5. Исправлены кнопки

Кнопки `Назад`, `Закрыть`, `Далее` и `Завершить` закреплены внутри нижней области панели.

KOI не перекрывает кнопки, включая шаг Раменной.

### 6. Короткие контролируемые тексты

Реплики разбиты на короткие строки, чтобы они стабильно помещались в рамку на desktop и mobile.

Текст шага Разломов использует формулировку **«битвы с ёкаями»**.

### 7. Сохранена лёгкая анимация

KOI сохраняет очень мягкое idle-движение. Оно отключается при `prefers-reduced-motion`.
